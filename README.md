# My Django Project

Простой веб-проект на Django с использованием Bootstrap для стилизации.

---

## Описание

Этот проект создан для демонстрации работы с Django. Он включает в себя:
- Главную страницу с товарами.
- Страницу контактов.
- Блог с возможностью создания, редактирования, удаления и просмотра записей.
- Использование шаблонов и статических файлов.

---

## Требования

- Python 3.8+
- Django 4.2+
- Pillow (для работы с изображениями)
- Psycopg2 (если используется PostgreSQL)

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш-никнейм/название-репозитория.git
   cd название-репозитория


2. Создайте и активируйте виртуальное окружение:

   ```bash
    python -m venv venv
- На Windows: 

   ```bash
    venv\Scripts\activate

- На macOS/Linux:

   ```bash
    source venv/bin/activate

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt

## Настройка

1. Создайте файл .env в корне проекта и укажите настройки базы данных:

DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432

2. Примените миграции:

   ```bash
   python manage.py migrate
   
## Запуск

1. Перейдите в директорию проекта:

   ```bash
   cd my_django_project
   
2. Запустите сервер разработки:

   ```bash
   python manage.py runserver
   
3. Откройте браузер и перейдите по адресу:

- http://127.0.0.1:8000/ — главная страница.
- http://127.0.0.1:8000/contacts/ — страница контактов.
- http://127.0.0.1:8000/blogs/ — блог.
- http://127.0.0.1:8000/categories/ — категории.

## Структура проекта

- catalog/ — приложение каталога товаров.
- blog/ — приложение блога.
- templates/ — шаблоны.
- static/ — статические файлы (CSS, JS, изображения).
- media/ — загруженные пользователями файлы (изображения).

## Использование

- На главной странице отображаются товары.
- В блоге можно создавать, редактировать, удалять и просматривать записи.
- На странице категорий можно управлять категориями товаров (создавать, редактировать, удалять).
- На странице контактов отображается информация для связи.

## Валидация форм

- Для товаров реализована валидация на запрещённые слова в названии и описании.
- Запрещены следующие слова: казино, криптовалюта, крипта, биржа, дешево, бесплатно, обман, полиция, радар.
- Реализована валидация цены: цена не может быть отрицательной.

## Стилизация форм

- Все формы стилизованы с использованием Bootstrap.
- Поля форм имеют класс form-control для единообразного оформления.
